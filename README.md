# R7LocalServer

Десктопное приложение — локальный HTTP-сервер для плагинов Р7 Офис.

Плагины Р7 Офис выполняются в браузерном контексте и не имеют прямого доступа к файловой системе и корпоративным сетевым ресурсам. R7LocalServer запускается на рабочем месте пользователя и предоставляет REST API, через который плагины могут читать и записывать файлы, выполнять HTTP-запросы с Windows-аутентификацией и синхронизировать макросы между книгами.

## API

Все запросы — `POST`, тело и ответ — JSON (`Content-Type: application/json`).

---

### Диагностика

#### `GET /ping`

Проверка доступности сервера.

**Ответ:**
```json
{
  "status": "ok"
}
```

---

### Файлы

Поддерживаемые форматы: `json`, `txt`, `csv`, `xml`, `xls`, `xlsx`.

#### `POST /files/write`

Записывает файл на диск.

**Запрос:**

```json
{
  "directoryPath": "D:\\shared",
  "fileName": "data.json",
  "overwrite": false,
  "content": { }
}
```

| Поле            | Тип     | Обяз. | Описание                                          |
|-----------------|---------|:-----:|---------------------------------------------------|
| `directoryPath` | string  |  ✓   | Абсолютный путь к папке                           |
| `fileName`      | string  |  ✓   | Имя файла с расширением                           |
| `overwrite`     | boolean |       | Перезаписать если существует (по умолчанию false) |
| `content`       | any     |  ✓   | Содержимое файла                                  |

**Ответ:**

```json
{
  "success": true,
  "path": "D:\\shared\\data.json",
  "fileType": "JSON"
}
```

---

#### `POST /files/read`

Читает файл с диска.

**Запрос:**

```json
{
  "directoryPath": "D:\\shared",
  "fileName": "data.xlsx",
  "readMode": "DEFAULT"
}
```

| Поле            | Тип    | Обяз. | Описание                                                 |
|-----------------|--------|:-----:|----------------------------------------------------------|
| `directoryPath` | string |  ✓   | Абсолютный путь к папке                                  |
| `fileName`      | string |  ✓   | Имя файла с расширением                                  |
| `readMode`      | string |       | Режим чтения Excel: `DEFAULT`, `RAW`, `TYPED` (см. ниже) |

**Режимы чтения Excel:**

| Режим     | Описание                                                                         |
|-----------|----------------------------------------------------------------------------------|
| `DEFAULT` | Автоматический выбор: значения типизированы по содержимому                       |
| `RAW`     | Возвращает сырые строки без конвертации типов                                    |
| `TYPED`   | Возвращает ячейки с явно указанным типом (`string`, `number`, `boolean`, `date`) |

**Ответ:**

```json
{
  "directoryPath": "D:\\shared",
  "fileName": "data.xlsx",
  "fileType": "XLSX",
  "lastModifiedAt": "2024-01-15T10:30:00",
  "content": { }
}
```

### Excel

#### `POST /export/excel-sheets`

Записывает листы с данными в Excel-файл. Читает шаблон из источника, заполняет указанные листы и сохраняет результат.

**Запрос:**

```json
{
  "sourceDirectoryPath": "D:\\templates",
  "sourceFileName": "template.xlsx",
  "targetDirectoryPath": "D:\\output",
  "targetFileName": "report.xlsx",
  "overwrite": false,
  "sheets": [
    {
      "name": "Лист1",
      "cells": [
        { "row": 0, "col": 0, "value": "Текст" }
      ]
    }
  ]
}
```

| Поле                  | Тип     | Обяз. | Описание                        |
|-----------------------|---------|:-----:|---------------------------------|
| `sourceDirectoryPath` | string  |  ✓   | Папка с шаблоном                |
| `sourceFileName`      | string  |  ✓   | Имя файла шаблона               |
| `targetDirectoryPath` | string  |  ✓   | Папка для сохранения результата |
| `targetFileName`      | string  |  ✓   | Имя результирующего файла       |
| `overwrite`           | boolean |       | Перезаписать если существует    |
| `sheets`              | array   |  ✓   | Листы с ячейками для записи     |

**Ответ:**

```json
{
  "targetDirectoryPath": "D:\\output",
  "targetFileName": "report.xlsx",
  "exportedSheetNames": ["Лист1"]
}
```

### Прокси

#### `POST /proxy/request`

Выполняет HTTP-запрос от имени сервера. Поддерживает аутентификацию, включая NTLM и Negotiate (Kerberos) для корпоративных ресурсов.

**Запрос:**

```json
{
  "url": "https://intranet.company.local/api/data",
  "method": "GET",
  "headers": { "Accept": "application/json" },
  "body": null,
  "authType": "NTLM",
  "username": "user",
  "password": "pass",
  "domain": "CORP",
  "ignoreSslErrors": false
}
```

| Поле              | Тип     | Обяз. | Описание                                                 |
|-------------------|---------|:-----:|----------------------------------------------------------|
| `url`             | string  |  ✓   | URL запроса                                              |
| `method`          | string  |       | HTTP-метод (по умолчанию `GET`)                          |
| `headers`         | object  |       | Заголовки запроса                                        |
| `body`            | string  |       | Тело запроса                                             |
| `authType`        | string  |       | Тип аутентификации: `NONE`, `BASIC`, `NTLM`, `NEGOTIATE` |
| `username`        | string  |       | Логин                                                    |
| `password`        | string  |       | Пароль                                                   |
| `domain`          | string  |       | Домен Windows (для `NTLM`)                               |
| `ignoreSslErrors` | boolean |       | Игнорировать ошибки SSL-сертификата                      |

**Ответ:**

```json
{
  "status": 200,
  "headers": { "Content-Type": "application/json" },
  "body": "..."
}
```

## Плагины Р7 Офис
В репозитории находятся готовые плагины для Р7 Офис (папка `plugins/`), использующие API R7LocalServer.

### Установка

1. Скачайте плагины из релиза
2. Откройте Р7 Офис → **Плагины** → **Настройки** → **Добавить плагин**.
3. Укажите файл плагина (`Macros Sync.plugin` или `Macros Sync Companion.plugin`).
4. Повторите для каждого плагина.

Установщик R7LocalServer размещает или обновляет оба плагина в папке Р7 Офис
для текущего пользователя. При удалении сервера он удаляет и эти плагины.

Для проверки обновлений через Companion нужны **оба** плагина.

---

### Macros Sync

Версионная библиотека макросов: прямое сравнение книги с библиотекой, публикация
с трёхсторонним слиянием, применение библиотечной версии к книге и история изменений.

- **Включить историю** — зарегистрировать существующий JSON, сохранив исходный снимок.
- **Сохранить выбранные в библиотеку…** — просмотреть и опубликовать выбранные
  универсальные макросы. Документ не изменяется.
- **Применить к документу…** — просмотреть и применить версию библиотеки к выбранным
  макросам книги. Перед записью создаётся отдельная резервная копия. После применения
  сохраните книгу в Р7.
- **История библиотеки** — просмотреть восстановление старой версии и сохранить
  результат новой версией.
- **Восстановить копию документа** — просмотреть и восстановить сохранённый объект макросов.

Настройки: адрес сервера, общая папка, имя JSON, необязательная папка резервных копий,
проверка обновлений и автоматическое применение изменённых макросов в Companion.
Без явно указанной папки копии хранятся в
`macro-backups` в папке состояния R7LocalServer. Флаг «не проверять» исключает
макрос из проверки Companion, сохраняя возможность ручной загрузки.

При сохранении в библиотеку конфликтующие правки можно разрешить выбором версии
документа или библиотеки, отдельного участка либо ручным редактированием итога.
Без известной исходной версии разные макросы не объединяются автоматически.
Отмена просмотра ничего не записывает.

[Контракт API v2, формат хранения, восстановление после сбоев и проверки в Р7](docs/MACRO_SYNC_V2.md).

### Macros Sync Companion

Companion проверяет отличия книги от библиотеки при открытии и по кнопке **Проверить**.
Основной плагин показывает те же отличия в списках. Сравниваются код и общие свойства
макросов по GUID; локальные флаги книги не учитываются. Если включено **Всегда обновлять**,
Companion автоматически заменяет изменённые макросы версиями из библиотеки. Кнопка
**Применить все** также добавляет отсутствующие в книге макросы из библиотеки.
Перед записью создаётся резервная копия; после применения сохраните книгу в Р7.
Пометка «не проверять» исключает макрос из автоматического применения.
Настройки `macrosSync_*` сохраняются в основном плагине.

Перед включением истории обновите сервер и оба плагина на всех компьютерах.
История хранится рядом с JSON в `<имя-файла>.history`; переносите их вместе.
Для общей сетевой папки предварительно проверьте блокировки и атомарную замену
с двух компьютеров. Старые серверы не должны записывать эту библиотеку.

---

При ошибке сервер возвращает соответствующий HTTP-статус и JSON:

```json
{
  "status": 400,
  "message": "File already exists"
}
```

| Статус | Причина                                                                                    |
|--------|--------------------------------------------------------------------------------------------|
| `400`  | Некорректный запрос: пустые поля, неверный режим, файл уже существует и `overwrite: false` |
| `404`  | Файл не найден                                                                             |
| `409`  | Устаревший просмотр, занятая библиотека или конфликт версионности макросов                  |
| `500`  | Внутренняя ошибка сервера                                                                  |

## Сборка из исходников

Для сборки требуется JDK 21. Укажите его в `JAVA_HOME` и в настройках Gradle JVM вашей IDE. Используйте Gradle Wrapper из репозитория; при первом запуске нужен доступ к репозиториям зависимостей и серверу загрузки Gradle.

Компиляция и запуск тестов в Windows (PowerShell):

```powershell
.\gradlew.bat :composeApp:jvmTest --console=plain
```

Сборка каталога приложения со встроенной Java:

```powershell
.\gradlew.bat :composeApp:createDistributable --console=plain
```

В Windows результат находится в `composeApp/build/compose/binaries/main/app/R7LocalServer`; для запуска используйте `R7LocalServer.exe` внутри этого каталога.

В Linux и macOS используйте `./gradlew` вместо `.\gradlew.bat`. Дистрибутив собирается для текущей операционной системы.

## Используемые библиотеки

- **Compose Multiplatform, Material 3 и AndroidX Lifecycle** — интерфейс приложения.
- **Ktor, kotlinx.serialization и Kotlin Coroutines** — локальный HTTP-сервер и обработка запросов.
- **Apache HttpClient 5** — исходящие HTTP-запросы с Windows-аутентификацией.
- **Apache POI и kotlin-csv** — работа с Excel и CSV.
- **JGit** — сравнение и объединение кода макросов.
- **Logback** — журналирование.

Плагины используют API Р7 Офис. Точный состав зависимостей и их версии указаны в [каталоге Gradle](gradle/libs.versions.toml).
